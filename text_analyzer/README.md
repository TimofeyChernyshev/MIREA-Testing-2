# Функционал

- `count_words` - подсчет слов в тексте
- `count_chars` - подсчет символов, в параметрах флаг на учет пробелов, по дефолту `True`
- `word_frequency` - частота слов без учета регистров и знаков препинания
- `most_common_word` - самое частое слово. Возвращает `None` для пустого текста
- `is_palindrome` - является ли текст палиндромом без учета регистров и знаков препинания
- `unique_words` - множество уникальных слов в нижнем регистре
